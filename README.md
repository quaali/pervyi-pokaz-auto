# Первый показ

Демоверсия сайта гаража предпродажной подготовки авто. На сайте можно выбрать услуги и собрать текст заявки. Форма работает в браузере, а заявка остаётся черновиком.

## Как открыть сайт на компьютере

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и откройте `index.html` в браузере. Устанавливать программы для запуска сайта и собирать проект не нужно.
